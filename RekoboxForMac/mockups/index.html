RekoBox · macOS / Apple Silicon

界面效果图 · 与 Windows 同构

同一套 Qt 6.7 Widgets 代码（mainwindow.ui + neko.css）在 macOS 上编译， 界面内容与排版完全一致；系统只接管了四处：屏幕顶部菜单栏、窗口红绿灯、菜单栏状态项、系统字体。 A 组是"和 Windows 一样"，B 组是加一层 Mac 外壳的可选方案，C 组为首选项窗口。

配色与控件基准
强调色 / 选中 延迟 < 100 ms 100–200 ms > 200 ms 超时

所有窗口按现有 mainwindow.ui 的真实控件尺寸重绘（工具栏 62px、标签 28px、表格行 30px、状态栏 28px）， QSS 基础为 Fusion + neko.css。真实 Qt 渲染的字体度量会有 1–2px 差异，不影响布局判断。
