客户端怎么用

Windows 客户端：顶栏「首选项」→「账号与节点订阅」→ 填服务器地址、账号、口令 → 登录。 登录后自动拉一次节点；之后每次启动、每 30 分钟、以及手动点「立即拉取」时更新。

只读模型

客户端登录后只有一个数据入口 GET /api/v1/nodes。 服务端不存在任何客户端上传接口，PUT /api/v1/vault 一律返回 403。 因此任何一个用户都无法改动别人看到的节点列表。

权限组（谁能拉哪些节点）

在「权限组」页签建组 → 点「配置节点」勾上这个组能访问的节点 → 再到「账号管理」把账号分配进去。 一个账号可以属于多个组，可见节点取并集；管理员账号不受限制，始终能看到全部节点。
未分配权限组的账号按页签顶部的兜底策略处理：open 可见全部启用节点（升级前的默认行为）， closed 什么都看不到。收紧权限时先把账号分好组，再切 closed。
权限组或归属一改，节点池版本自动 +1，客户端下次拉取（含 ?version= 增量查询）就会拿到新结果， 客户端不需要改代码。

新增节点

直接把机场/自建的分享链接粘进来，一行一条。支持的协议： vmess vless trojan ss socks5 http tuic hysteria2 naive+https。 禁用节点不会下发；删除节点后，客户端下次拉取会把它从本地移除，同时它也会从各权限组里摘掉。

命令行

rekosync -addadmin root -password '...'   # 建管理员
rekosync -adduser  alice -password '...'  # 建普通账号
rekosync -users                           # 列账号（含权限组）
rekosync -passwd alice                    # 改口令（踢掉旧令牌）
rekosync -disable alice / -enable alice   # 禁用 / 启用
rekosync -addgroup 套餐A                   # 建权限组
rekosync -groups                          # 列权限组
rekosync -groupnodes "套餐A=id1,id2"       # 配置可访问节点
rekosync -usergroups "alice=套餐A"         # 分配权限组
rekosync -acl closed                      # 未分组账号看不到节点

接口一览

POST /api/v1/auth/login
{username, password, device} → {token, user.role, user.groups}
GET /api/v1/nodes
已登录账号：其权限组内启用中的节点（只读）
GET /api/v1/admin/nodes
管理员：全量节点（含禁用）
POST /api/v1/admin/nodes
管理员：{links, group, remark} 批量录入
PATCH /api/v1/admin/nodes/{id}
管理员：改名/分组/备注/启用/换链接
GET|POST /api/v1/admin/groups
管理员：权限组列表 / {name, description, nodes?}
PATCH|DELETE /api/v1/admin/groups/{id}
管理员：改名 / 删组（连带摘掉账号归属）
POST /api/v1/admin/groups/{id}/nodes
管理员：{ids:[...]} 设置该组可访问的节点
POST /api/v1/admin/users/{name}/groups
管理员：{groups:[组id]} 设置账号归属
POST /api/v1/admin/acl/policy
管理员：{default_policy:"open"|"closed"}
